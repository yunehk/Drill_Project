# 2차 발표 구현 현황

작성 기준: 2026-11-16. 모든 표기는 실제 코드 기준이며 8스테이지/4종 전체 완성으로 표현하지 않습니다.

| 1차 계획 | 이번 확인 결과 | 상태 |
|---|---|---|
| 1주차: 조준·입력·충돌 개선 | 기존 투척 조작 유지. 새 전투방에 탑승·하차, 고정 방향 돌진, 착탄 위치 표시, 벽 충돌 추가 | 해당 기능 구현·자동 검증 |
| 2주차: 세 방의 레벨 디자인 | 기존 세 방 유지. 몸 탈취 신규 3스테이지 추가. 단계별 학습·교체·교차 사격 및 순차 진행 구현 | 부분 진행 |
| 3주차: 캐릭터 이미지와 연출 | 임시 도형 렌더링, 기절/공격 예고, 파편, 효과음, 화면 흔들림 구현. 최종 스프라이트 없음 | 부분 진행 |
| 4주차: 플레이 테스트와 마무리 | 자동 규칙·진행 검사, 실제 렌더러 캡처, 입력 UI 검사 실시. 사용자 플레이에 따른 재미/난이도 검증은 예정 | 부분 진행 |

## 기획 변경

- 변경 전: 자기 갑옷 2겹을 벗고 회수하면서 열쇠와 출구를 찾는 퍼즐.
- 변경 이유: 작은 몸으로 우회하는 플레이에 치우치고, 갑옷 활용과 전투 판단의 필요성이 약하다는 설계 우려.
- 변경 후: 공격을 피해서 기절을 유도하고 적의 몸을 탈취. 돌진형으로 포격형의 장갑을 깨고, 포격으로 길을 연 뒤 작은 몸으로 탈출.
- 현재 구현: 돌진형·포격형 2종, 순차 진행하는 신규 3스테이지. 기존 세 방은 `--classic`으로 실행.
- 향후 계획: 자석형·거미형, 기체 간 상호작용, 최대 8스테이지, 최종 아트, 난이도 튜닝. 현재 구현된 기능으로 발표하지 않음.

## 확인할 한계

- 3스테이지 프로토타입이며 완성 게임이나 8스테이지 캠페인이 아닙니다.
- QA 입력 경로의 일반 모드 클리어는 확인했지만, 사람의 직접 플레이를 통한 재미 검증은 남아 있습니다.
- 적 종류, 이동 패턴, 기체 체력과 기절 시간은 플레이 테스트 후 조정할 수치입니다.
- 녹화 프로그램의 캡처와 음성 품질은 내일 본인이 확인해야 합니다.

## 3스테이지 확장

1. 탈취의 시작: 돌진형만 등장. 돌진으로 균열벽 파괴.
2. 몸 바꾸기: 돌진형으로 포격형을 탈취하고 포격으로 차단벽 파괴.
3. 교차 사격: 새로운 엄폐물과 독립 포탑, 예고 후 작동하는 주기 레이저 추가.

클리어 후 Enter로 다음 방, R로 현재 방 재시작. 시작 화면 1/2/3으로 방 선택.
각 방의 체력과 기체는 초기화하며, 이전 방 클리어 시간은 순차 진행 중 유지합니다.
